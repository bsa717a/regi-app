# Utah plate preview images

Official Utah DMV license-plate catalog art, downloaded from
[dmv.utah.gov/plates](https://dmv.utah.gov/plates/license-plates/)
for local previews in the REGI personalized-plate flow.

These are government catalog illustrations so customers can recognize
plate designs. They are not REGI-created art. Files are stored under
`public/plates/utah/` instead of hotlinked so they keep loading if the
DMV CDN path changes.
