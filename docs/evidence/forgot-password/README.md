# Forgot-password prominence evidence (PR #75)

Screenshots of the login and reset-password flows after making **Forgot
password?** more visible and adding inline error guidance.

Captured from the running app (mobile + desktop login, wrong-password
inline CTA, and the forgot-password page). `staging_login_before_buried_link.png`
is the optional before shot of the buried link on staging.

These files are in-repo so Hub can pull them via `raw.githubusercontent.com`
without a GitHub click-through.
